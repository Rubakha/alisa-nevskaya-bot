# Подложка для «Голосового письма»

Сюда кладут фоновые треки (`.mp3`, `.ogg`, `.wav`, `.m4a`, `.flac`) — спокойные, без вокала, лучше фортепиано/струнные/эмбиент.
Бот берёт один трек на заказ (по номеру заказа), зацикливает под длину голоса, делает плавный вход и затухание
и сводит на громкости **−22 dB** относительно голоса (`VOICE_MUSIC_DB`, допустимо −20…−25).

**Нельзя** класть треки без права коммерческого использования: «бесплатно скачать» ≠ «можно в платном продукте».
Подходят только треки с лицензией, прямо разрешающей коммерческое использование в сервисе (CC0, CC-BY с указанием автора
в описании бота, платная лицензия Artlist/Epidemic/Pixabay и т.п.). Лицензию и источник сохраняйте вне репозитория.

Треки (по 40 с, без вокала): `alisa_letters.mp3`, `alisa_theme_piano.mp3`, `alisa_winter.mp3` (зимний: играет только с 15.11 по 10.01).

**Источник и лицензия:** Eleven Music, ElevenLabs, коммерческая лицензия по подписке владельца, 09.10.2026. 
Остальные треки библиотеки (`alisa_rain`, `alisa_morning`, `alisa_finale`) лежат в ai-content-pipeline/assets/music, при необходимости можно добавить.

Если папка пуста — голосовое письмо уходит только с голосом, без музыки.
