# Корпоративная линейка к Новому году (B2B)

Продажи с 01.11 (`B2B_SALES_START`, по умолчанию 2026-11-01). До даты меню видно всем, заказ создают только
админ и тестовые аккаунты; остальным — кнопка «Напомните мне» (список в `DATA_DIR/b2b/interest.json`).

## Файлы
- `b2b_config.py` — цены, лимиты, тона. **Все цифры только здесь.**
- `b2b_ai.py` — промпт «письмо-подарок» (одна правдивая мысль о человеке, на «вы», без рекламы).
- `b2b_core.py` — проекты на диске, разбор CSV/XLSX/текста, логотип, открытки, пакетная генерация, ZIP, таблица.
- `b2b.py` — хендлеры Telegram и админ-команды.
- В `bot_best.py` — 5 строк: импорт/регистрация, `?start=b2b`, ветка в `fulfill_order`, кнопка «🏢 Для компаний».

## Путь заказчика
`?start=b2b` или «🏢 Для компаний» → пакет → анкета (компания, тон, подпись, логотип; для «коллективу» — открытка
отдела) → список (CSV/XLSX/текст: имя, роль, деталь) → 3 превью (до 3 раундов) → оплата → генерация с прогрессом →
ZIP открыток (логотип в углу) + таблица «имя → текст».

Оплата: до `SMALL_PAY_LIMIT` (15 000 ₽) — карта/СБП как в B2C (обычный заказ `product="b2b"`); любая сумма —
«Счёт для юрлица»: заказчик присылает реквизиты, админу приходит заявка, после поступления денег админ пишет
`/b2b_paid B2B-XXXXXX` — и запускается генерация.

## Админ
- `/b2b` — список, оплаты, выручка; `/b2b ID` — детали и реквизиты.
- `/b2b_paid ID` — подтвердить оплату по счёту.
- `/b2b_retry ID` — дописать письма, которые не получились (дошлются отдельным архивом «_дополнение»).

## Переменные окружения
`B2B_SALES_START`, `B2B_REQUISITES` (ваши реквизиты для счёта — показываются юрлицам), `B2B_PARALLEL` (параллельных
запросов к модели, по умолчанию 3).

## Ограничения
- Бот не рассылает письма чужим людям — только заказчику.
- «Дни рождения команды» — каркас: заявка админу, подключение вручную.
- Оплата по счёту не попадает в общую статистику заказов — только в `/b2b`.
