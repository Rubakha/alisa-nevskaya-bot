# 💌 Бот «Алиса Невская»

Telegram-бот для продажи персональных писем. Оплата картой через ЮKassa,
личный кабинет клиента, карточки характера, админ-панель, Claude-помощник.

---

## Файлы

| Файл | Что это |
|---|---|
| `bot_best.py` | весь бот, 2160 строк — главный файл |
| `ai_assistant.py` | Claude-помощник: разборы, черновики, сводки |
| `requirements.txt` | зависимости |
| `render.yaml` | конфиг Render с диском (можно просто положить в репозиторий) |
| `Procfile` | команда запуска |
| `.env.example` | шаблон переменных — скопируй в `.env` |

---

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env      # вписать TG_BOT_TOKEN, ADMIN_ID, YOOKASSA_PROVIDER_TOKEN
python bot_best.py
```

Без `WEBHOOK_URL` бот сам поднимется в режиме polling — удобно для проверки.

## Деплой на Amvera (оплата российской картой)

Конфиг — `amvera.yml` в корне репозитория (сборка pip, вход `bot_best.py`,
постоянный диск на `/data`, работа в режиме polling — вебхук/домен не нужны).

1. amvera.ru → зарегистрируйся, New Project → Import from Git → укажи
   `https://github.com/Rubakha/-`.
2. На странице проекта нажми **Generate YAML** — если сгенерированный файл
   отличается от `amvera.yml` в репозитории, замени содержимое на то, что
   даёт кнопка (я собрал `amvera.yml` по документации, но не проверял вживую
   — интерфейс Amvera мог поменяться).
3. Settings → Environment variables → добавь `TG_BOT_TOKEN`, `ADMIN_ID`,
   `YOOKASSA_PROVIDER_TOKEN`, `ANTHROPIC_API_KEY`. **`WEBHOOK_URL` не
   указывай** — бот сам поднимется в режиме polling, без домена и SSL.
4. Deploy. В логах должно появиться `polling mode` и `storage ready`.

Обновления: `git push` в свой GitHub → Amvera передеплоит сама (если включена
интеграция), либо `git push amvera master` напрямую в её git-remote.

## Деплой на Render (альтернатива, нужна валютная карта)

1. New → Web Service → выбрать репозиторий.
2. План **Starter** (на бесплатном нет диска).
3. Disks → Add Disk: mount path `/var/data`, размер 1 ГБ.
4. Environment → добавить переменные из `.env.example` (включая `YOOKASSA_PROVIDER_TOKEN`).
5. После деплоя открыть `/health` — должно быть
   `"writable": true` и `"persistent": true`.

Диск отключает zero-downtime: при каждом деплое бот недоступен 10–20 секунд.
Для писем это незаметно.

## Что умеет клиент

- Выбор формата с **отрывком письма** и параметрами до оплаты
- **Резюме заказа** перед платежом: цена, срок, текст вопроса, гарантия
- Оплата картой через ЮKassa, после оплаты — номер заказа и дата готовности
- Кабинет: заказы со статусами, чтение готовых писем, оценка звёздами
- Оценка 3 и ниже → автоматическое предложение переписать бесплатно
- Подарочные письма: «вопрос напишу я» или ссылка для друга
- Реферальная программа: 50 ₽ за оплаченное письмо друга

## Что умеет автор

- Заказы с фильтрами: в работе / не оплачены / готовы / все
- У каждого заказа готовая команда `/write_ALI_...`
- **Карточка клиента** приходит перед написанием письма: история вопросов,
  оценки, метки, заметки
- Заметки свободным текстом, метки — 14 кнопок
- Статистика: выручка, средний чек, средняя оценка, разбивка по форматам
- Рассылка с предпросмотром и подтверждением
- Экспорт в Excel, бэкап zip, раздел «Диск»
- `/reply CHAT_ID текст` — ответ в поддержку
- Автобэкап в чат раз в неделю

## Claude-помощник (если задан ключ)

Кнопки при написании письма:
- **🔍 Разобрать вопрос** — о чём спрашивают на самом деле, чего боятся,
  какое разрешение нужно, что писать нельзя
- **✏️ Черновик** — письмо голосом Алисы с учётом карточки и заметок

Ещё: предложение меток для карточки, черновик ответа в поддержку,
сводка по заказам за 7 и 30 дней.

**Важно:** помощник ничего не отправляет клиентам. Черновик приходит тебе,
клиенту уходит только тот текст, который ты пришлёшь сам.

Стоимость: разбор + черновик ≈ 3 ₽ на письмо (Sonnet).

## Данные

```
$DATA_DIR/

  clients/123456789.json        профили, заметки, метки
  exports/                      выгрузки Excel и бэкапы
```

диск живёт внутри их инфраструктуры и снапшоты сам не делает.

- [ ] Подключить ЮKassa в @BotFather → твой бот → Payments → вписать
      `YOOKASSA_PROVIDER_TOKEN` в `.env` / Render
- [ ] Тест-заказ со второго аккаунта с реальной оплатой
- [ ] `/health` показывает `persistent: true`
- [ ] `BOT_USERNAME` совпадает с настоящим именем бота
- [ ] Отзывы в коде (`REVIEWS`) — пока выдуманные, заменить на настоящие
      или убрать до публичного трафика
- [ ] Решить вопрос налогового статуса до первых крупных сумм

Комиссия ЮKassa обычно ниже, чем у Telegram Stars (~30%) — уточни свой тариф
в личном кабинете kassa.yandex.ru при подключении.

## 🎙 Голосовое письмо (премиум, 390 ₽)

Письмо, прочитанное голосом ElevenLabs с тихой музыкой: голосовое сообщение (ogg/opus) + mp3.
Апселл «Озвучить голосом — +N ₽» после обычного письма и пункт «Голосовое письмо» в каталоге.
Код: `voice_letter.py` (TTS, ffmpeg, учёт символов), `voice_flow.py` (диалог бота), тесты — `tests/test_voice_letter.py`.

Переменные окружения (без `ELEVENLABS_API_KEY` и хотя бы одного id голоса функция скрыта):

| Переменная | Что это |
|---|---|
| `ELEVENLABS_API_KEY` | ключ API ElevenLabs |
| `ELEVENLABS_VOICE_ID_F` / `ELEVENLABS_VOICE_ID_M` | id женского / мужского голоса (достаточно одного) |
| `ELEVENLABS_MODEL` | модель, по умолчанию `eleven_multilingual_v2` (русский поддерживает) |
| `VOICE_LETTER_PRICE` | цена пункта каталога, ₽ (по умолчанию 390) |
| `VOICE_UPSELL_PRICE` | фиксированная доплата «Озвучить голосом» к обычному письму, ₽ (по умолчанию 100) |
| `VOICE_MUSIC_DB` | громкость подложки, dB (по умолчанию −22) |
| `VOICE_PAUSE_SEC` | пауза между абзацами, сек (по умолчанию 0.8; 0 — без пауз) |

Музыка — `assets/music/` (см. README там: только треки с правом коммерческого использования, в репозиторий не коммитим).
Нужен `ffmpeg` в окружении; без него уходит только mp3 без музыки. Расход символов — `DATA_DIR/voice_usage.jsonl`
и поле `voice_chars` в заказе. Если озвучка упала после оплаты, админу приходит `/voice_retry <заказ>`.
