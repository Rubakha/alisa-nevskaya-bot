# 💌 Бот «Алиса Невская»

Telegram-бот для продажи персональных писем. Оплата звёздами Telegram,
личный кабинет клиента, карточки характера, админ-панель, Claude-помощник.

---

## Файлы

| Файл | Что это |
|---|---|
| `bot_best.py` | весь бот, 2160 строк — главный файл |
| `ai_assistant.py` | Claude-помощник: разборы, черновики, сводки |
| `requirements.txt` | зависимости |
| `render.yaml` | конфиг Render с диском (можно просто положить в репозиторий) |
| `Procfile` | команда запуска |
| `.env.example` | шаблон переменных — скопируй в `.env` |

---

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env      # вписать TG_BOT_TOKEN и ADMIN_ID
python bot_best.py
```

Без `WEBHOOK_URL` бот сам поднимется в режиме polling — удобно для проверки.

---

## Деплой на Render

1. Залить файлы в репозиторий GitHub.
2. New → Web Service → выбрать репозиторий.
3. План **Starter** (на бесплатном нет диска).
4. Disks → Add Disk: mount path `/var/data`, размер 1 ГБ.
5. Environment → добавить переменные из `.env.example`.
6. После деплоя открыть `/health` — должно быть
   `"writable": true` и `"persistent": true`.

Диск отключает zero-downtime: при каждом деплое бот недоступен 10–20 секунд.
Для писем это незаметно.

## Что умеет клиент

- Выбор формата с **отрывком письма** и параметрами до оплаты
- **Резюме заказа** перед платежом: цена, срок, текст вопроса, гарантия
- Оплата Telegram Stars, после оплаты — номер заказа и дата готовности
- Кабинет: заказы со статусами, чтение готовых писем, оценка звёздами
- Оценка 3 и ниже → автоматическое предложение переписать бесплатно
- Подарочные письма: «вопрос напишу я» или ссылка для друга
- Реферальная программа: 50 ₽ за оплаченное письмо друга

## Что умеет автор

- Заказы с фильтрами: в работе / не оплачены / готовы / все
- У каждого заказа готовая команда `/write_ALI_...`
- **Карточка клиента** приходит перед написанием письма: история вопросов,
  оценки, метки, заметки
- Заметки свободным текстом, метки — 14 кнопок
- Статистика: выручка, средний чек, средняя оценка, разбивка по форматам
- Рассылка с предпросмотром и подтверждением
- Экспорт в Excel, бэкап zip, раздел «Диск»
- `/reply CHAT_ID текст` — ответ в поддержку
- Автобэкап в чат раз в неделю

## Claude-помощник (если задан ключ)

Кнопки при написании письма:
- **🔍 Разобрать вопрос** — о чём спрашивают на самом деле, чего боятся,
  какое разрешение нужно, что писать нельзя
- **✏️ Черновик** — письмо голосом Алисы с учётом карточки и заметок

Ещё: предложение меток для карточки, черновик ответа в поддержку,
сводка по заказам за 7 и 30 дней.

**Важно:** помощник ничего не отправляет клиентам. Черновик приходит тебе,
клиенту уходит только тот текст, который ты пришлёшь сам.

Стоимость: разбор + черновик ≈ 3 ₽ на письмо (Sonnet).

## Данные

Всё в JSON на диске, запись атомарная:

```
$DATA_DIR/
  orders/ALI-1234567890.json    заказы
  clients/123456789.json        профили, заметки, метки
  exports/                      выгрузки Excel и бэкапы
  backup_state.json             метка последнего автобэкапа
```

Бэкап раз в неделю приходит тебе в чат. Сохраняй копию вне Render —
диск живёт внутри их инфраструктуры и снапшоты сам не делает.
